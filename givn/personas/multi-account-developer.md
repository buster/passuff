# Persona: multi-account-developer

Confirmed: 2026-11-02 by the operator's brief and the instruction to proceed
with this change.

## Goal

Stay informed about activity on the GitHub pull requests they authored without
watching each repository or account manually.

## Context

The developer uses at least a personal and a work GitHub account, on a Linux or
macOS workstation. They keep a terminal open, want a short plain-text
transcript, and accept a desktop notification and a short sound for activity
that needs attention.

## Relevant outcomes

- Sees other people's comments and reviews on their own pull requests.
- Sees CI failures and recoveries.
- Sees merges and closes, including short-lived pull requests.
- Is not interrupted by their own comments or reviews, code pushes, metadata
  churn, bot comments (unless enabled), or other people's pull requests.
- Can stop the watcher and still read what happened.
