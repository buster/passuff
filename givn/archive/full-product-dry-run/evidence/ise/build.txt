== passuff --help (first 20)
Watches the GitHub pull requests you authored, are assigned to, or must review, and notifies you about other people's comments, reviews, CI failures and recoveries, and merged or closed pull requests.

Usage: passuff [OPTIONS] [COMMAND]

Commands:
  check        Run one observation pass and print notifications
  status       Show accounts, watch scope, watched pull requests, and unread count
  inbox        List unread activity; --all includes read activity
  read         Mark one activity record read
  setup        Create the configuration interactively
  notify-test  Send one test notification and play the configured sound
  help         Print this message or the help of the given subcommand(s)

Options:
      --config <PATH>
          Use a specific configuration file

      --state <PATH>
          Use a specific state file
