Watch authored GitHub pull requests and notify on eligible activity

Usage: passuff [OPTIONS] [COMMAND]

Commands:
  check   Run one observation pass and print notifications
  status  Show accounts, watch scope, watched pull requests, and unread activity
  inbox   List unread activity, or all activity with --all
  read    Mark one activity read by id, or every activity with --all
  help    Print this message or the help of the given subcommand(s)

Options:
      --config <PATH>  
      --state <PATH>   
      --verbose        Enable diagnostic logs on stderr (debug unless RUST_LOG is set)
  -h, --help           Print help
  -V, --version        Print version
exit status: 0
