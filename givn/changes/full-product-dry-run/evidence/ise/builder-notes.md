## Assumptions

Contracts the Specification does not state, chosen explicitly so behaviour is
reviewable:

1. **Version-2 state shape.** Declared: version 2, accounts, last checks,
   watched pull requests with state/CI, activity history with ids and read
   flags, retention of 500, version-1 upgrade. Assumed field names and nesting
   (`accounts.<label>.pull_requests.<owner/repo#n>` with the observed fields,
   `activity[].event` tagged by kind). Affected: `core/src/state.rs`.
2. **Quarantine naming.** Corrupt or unknown-version state is renamed to
   `<state>.corrupt-<UTC timestamp>[-n]` in the same directory before an empty
   state is used. Affected: `core/src/state.rs`.
3. **Activity ids.** `a<n>` maps to a persisted monotonic counter
   (`next_activity_id`, starting at 1); ids are never reused after retention
   trimming. Affected: `core/src/state.rs`, `cli/src/runtime.rs`.
4. **Probe fingerprint.** A pull request counts as changed when its probe id,
   state, createdAt, updatedAt, headRefOid, or CI results differ from the last
   accepted probe, or it is new to the probe. Reconciliation seeds probe
   fingerprints from full observations. Affected: `core/src/core.rs`.
5. **Pacing.** The delay is `max(poll_interval, reset_seconds / remaining)`
   seconds; with `remaining <= 0` it is 60 seconds. Affected:
   `core/src/core.rs`.
6. **GraphQL request details.** `first: 100` for authored/probe/discovery
   connections, `search(..., type: ISSUE)`, `orderBy: {field: UPDATED_AT,
   direction: DESC}` for the probe, and a 20-second request timeout. Affected:
   `core/src/github.rs`.
7. **Sound playback arguments.** `paplay file`, `pw-play file`,
   `aplay -q file`, `canberra-gtk-play -f file`; `PASSUFF_SOUND_PLAYER` is split
   on whitespace and the file path is appended. The bundled sound is written to
   `$TMPDIR/passuff-notification.wav` before playback. Affected:
   `cli/src/delivery.rs`.
8. **gh invocation.** `gh auth token --user <login>`, and
   `gh auth login --web --git-protocol https --hostname github.com --scopes
   read:user` followed by a token check. Affected:
   `config/src/lib.rs`.
9. **`ui.json` schema.** `sort`, `direction`, `desktop`, `sound`,
   `unread_only`, `ignored_visible`, `filter` (as `pr:<key>`,
   `stack:<repo>#<n>`, or `unread`). Affected: `cli/src/tui/mod.rs`.
10. **TUI frame details.** Borders and exact column widths, the default
    `--snapshot` size (80x24), natural key ordering (`#2` before `#10`),
    newest-first `updated` order, and the initial observation cycle being a
    reconciliation. Affected: `cli/src/tui/*`.
11. **Read of an already-read id.** Reports `0 activity records read` because
    the wording counts changed records. Affected: `cli/src/runtime.rs`.
12. **TUI ignore persistence.** `x` writes `watched.ignored_pull_requests` in
    the configuration atomically; a failed write keeps the previous list and
    reports `cannot write configuration`. Affected: `cli/src/tui/mod.rs`.
13. **Setup prompt wording.** Only asserted strings are fixed; other prompts
    use short labelled questions (`Account label:`, `Auth [...]:`, `GitHub
    login:`, `Environment variable:`, `Token command:`, `Token file:`, `Add
    another account? [y/N]`, `Watch mode [all/selected]`, `Repositories
    (comma-separated)`), with bounded retries so EOF cannot loop. Affected:
    `config/src/lib.rs`.
14. **Status row order.** Watched pull requests are sorted by key
    (repository, numeric number) for deterministic output. Affected:
    `cli/src/render.rs`, `core/src/lib.rs`.
15. **Notification transcript composition.** Baselines print even when the same
    pass has notifications; delivery failures are stderr lines and do not
    change the exit code. Affected: `cli/src/render.rs`,
    `cli/src/runtime.rs`.
16. **TUI without configuration and without a terminal** exits 2 with a
    `passuff setup` hint (matching the setup use case example); with a
    configuration but no terminal it exits 3. Affected: `cli/src/tui/mod.rs`.
